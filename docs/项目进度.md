## 怎么跑起来

按 [README](../README.md) 操作。几个容易卡住的地方：

- **Windows 用 PowerShell 导入 SQL**：PowerShell 不支持 `<`，`mysql` 一般也不在 PATH 里，用 README 里写全路径、`source` 的那种写法，一次导一个文件。
- **验证码在后端控制台**：开发模式不真的发邮件，注册和教育邮箱的验证码打印在后端窗口里。
- **演示账号**：导入 `sql/demo.sql` 后有 11 个账号，账号、身份和统一密码写在这个文件开头的注释里。
- **数据库不用手工建**（`dev` 上）：后端第一次启动时自己建库、建表、填初始数据；以前手工建过的库第一次启动时自动补齐缺的表和字段。演示数据还是要手工导入一次，在后端启动过一次之后。
- **加分认定的演示内容**：以前导入过演示数据的，跑一次 `sql/demo-recognition.sql` 补上（写法和其他脚本一样，可以重复跑）；新导入的已经有了。
- **想直接看到铺开的需求雷达**：跑一次 `sql/demo-radar.sql`，给演示队伍的招募需求多补几项技能要求（可以重复跑，只把最低熟练度往高调，不会重复插入）。
- **演示比赛的报名截止了**：以前导入的演示数据日期是写死的，数学建模那届 10 月 15 日就截止报名了，建队、申请、同意申请都会被拦。跑一次 `sql/demo-refresh-dates.sql` 把日期挪到今天附近（不删数据，可以重复跑）；新导入的演示数据按导入那天自动往后排。

## 测评指引

建议按下面的顺序测。每一步做完，觉得哪里不对、不好用、看不懂，就在 GitHub 上提一个 Issue。

### 第一版功能

1. **注册和认证**：注册一个新账号；用 `xxx@stu.example.edu.cn` 认证（自动通过）；再试一个没收录学校的 `.edu.cn` 邮箱（进入待审核）。
2. **比赛库**：筛选、看详情、关注一届比赛。
3. **个人档案**：填资料、技能、履历。
4. **问卷**：先填快速版，再补完整版。
5. **推荐**：用林晓登录看首页和比赛页的"为你推荐"，看推荐理由是否说得通；用陈一舟登录，看"数模冲刺队"页面的"推荐邀请的人"。
6. **组队流程**：申请 → 队长同意或婉拒；队长邀请 → 对方接受；退队、移出、转让队长、解散。
7. **日历**：开关图层；新建一个和比赛时间重叠的个人日程，看撞期提醒；试试每周重复、只删某一次。
8. **站内信**：上面每一步对方是否收到消息，点消息能不能跳到对的页面。
9. **管理后台**（管理员账号）：数据看板、认证审核（吴迪和郑好在等审核）、比赛库管理、匹配配置（改一个权重，回去看推荐分数变没变）、账号停用。

### 二期功能

10. **互评**：用赵子航把"国一冲冲冲"标记为比赛结束 → 赵子航和钱多多分别交互评 → 两人都交完后揭晓 → 右上角"互评与信用"看信用分。
11. **信用分对推荐的影响**：用陈一舟看"数模冲刺队"的推荐，周可（往届互评一般）会被降分并提示。
12. **举报**：在别人的队伍页举报 → 管理员在"举报与信用"里处理 → 举报人收到结果。
13. **截图认证**：新注册一个账号 → "身份认证"选"学生证截图"，上传学信网学籍页截图或学生证照片（可以自己画一张假的测试）→ 看识别结果 → 管理员在"认证审核"里看原图和比对结果后通过。
14. **通知抓取**（管理员账号，要联网）：管理后台 → 通知抓取，点"立即抓取"，会访问数模、电赛、计设的官网，一两分钟内抓完。现在是 10 月，大部分通知都是今年已经办完的，会被自动忽略，在"已处理"里能看到原因；"待确认"里打开一条，核对依据和原文后采用 → 去比赛库管理看生成的草稿届次。也可以在"抓取来源"里编辑一个来源，点"试抓"看列表里每个链接的去留原因。
15. **实时推送**：开两个浏览器窗口（比如一个普通窗口、一个无痕窗口），分别登录队长和另一个同学。同学申请入队，队长那边不用刷新，右上角马上弹出提示、铃铛数字加一，点提示进入队伍页；队长同意后，同学那边也马上收到。再开一个队长的标签页，在一个页面里把消息标为已读，看另一个页面的数字是否跟着变。
16. **分工待办**：队伍页右侧时间线里，在某个节点下点"+ 加任务"。队长把任务分给某个队员，对方马上收到通知；队员认领没人负责的任务、勾完成；看节点名旁边的"任务 x/y"有没有跟着变。去"我的队伍"页看最上面的"分给我的待办"。
17. **我的主页**：用不同的演示账号登录看主页。陈一舟（队长）右栏有孙悦的申请，直接点同意；林晓（还没组队）中栏是适合报名的比赛，右栏是推荐队伍。看顶部的下一个节点和本周可投入时间是否说得通，左边日历和学期赛程带上的横条、菱形对不对。
18. **订阅到手机日历**：主页右上的"订阅到手机日历"，下载 .ics 导入电脑日历，看比赛节点、队伍节点、个人日程是否都在；点"重置链接"后旧链接应该打不开。
19. **一句话添加**：在主页赛程日历上方的输入框里试几句，比如"明天下午两点到四点 队伍开会""周五前交论文初稿""每周六上午9点到12点 数模集训 到11月30日""今晚11点到明早1点 赶论文""下个月找时间开始复习线代 大概两周"，看输入框下面认出来的日期、时间、重复和标题对不对，回车后日历上有没有、顶部"本周可投入"有没有跟着变；认得不对的点"细调"改，并把那句话发到 Issue 里。
20. **邮件提醒**：消息页上方有"邮件提醒"开关（默认打开）。关掉浏览器，让别人给你发一条申请或邀请，10 分钟后看后端控制台（开发模式）有没有打印一封发给你的汇总邮件；开着网站、或者 10 分钟内看过的不应该发。
21. **加分认定**：用林晓登录，比赛库里数学建模标着"本校 A 类"。打开计算机设计大赛，王思远标的 B 类还差 1 人确认，点"我也确认"就显示出来了，王思远会收到通知；再点"我知道的不一样"提交一个不同的级别，看原来的确认是不是自动撤掉。电子设计竞赛还没人标，可以试"标注本校的认定"。管理员在"管理后台 → 加分认定"里能看到所有标注，同校有分歧的会标出来，可以驳回。
22. **忘记密码和登录锁定**：登录页点"忘记密码？"，填注册邮箱，去后端控制台拿验证码，设新密码；之前在别的浏览器登录着的会被退出。再故意输错 5 次密码，第 6 次会提示 15 分钟后再试；没注册过的邮箱点"发送验证码"也提示已发送（不暴露谁注册过）。
23. **批量撮合（只给建议）**：用林晓登录，打开数学建模，"为你推荐"下面有"或者和这些同学一起组"：从孙悦、李想、周可里挑出的几种组合，带匹配度和推荐理由。点"按这个组合建队"，填队名保存，会进入新队伍页，组合里的人收到邀请；用孙悦登录接受邀请看看。已经在队里的人（比如陈一舟）看不到这一块。
24. **主页排版**（dev）：主页三栏一样宽。点日历右上角的「加宽」，日历变宽、右边两栏变窄（改版前的样子），按钮变成「收窄」；刷新页面后还是加宽的。窗口窄到两栏或一栏时不显示这个按钮。
25. **AI 帮我整理**（dev）：打开任意比赛，点标题旁的「AI 帮我整理」，右边滑出抽屉，顶上有"可能不全"的提醒，下面是更多信息渠道。要看到要点：管理员先在"通知抓取"里抓一次（要联网），后端打开大模型（见 README 的"比赛通知爬虫"），再在抽屉里点"整理"；之后用学生账号打开，经过的几步和要点会一条条出来，点"看原文"能看到通知里的原话。学生看不到"整理"按钮。
26. **匹配六边形**（dev）：陈一舟登录，主页右栏「推荐队友」上方有六边形，点林晓、孙悦、周可换着看；周可没填问卷，大部分轴写着"没数据"、整个六边形是虚线。点"叠上去对比"里的名字，第二个人画成虚线框。林晓登录看到的是推荐队伍的六边形。
27. **日历记号**（dev）：主页日历月视图里只有细线、菱形和小圆点。翻到 11 月，鼠标放到 9 日上，弹出陈一舟的"社团换届"和国赛比赛期间，写着撞了；点条目跳到比赛页。切到"周"视图照旧有文字。
28. **看板风险图和漏斗**（dev，管理员）：管理后台首页，"组队风险和漏斗"里左边是气泡图，右边是数学建模这一届的漏斗，掉得最多的一步标红。点计算机设计大赛的气泡（或下面表格的那一行），漏斗跟着换。下面的"推荐准不准"：演示数据里的申请是开始记分之前的，会显示"还没有可以对比的记录"；用学生账号申请一支队、队长同意或婉拒后，再刷新看板，对应分数段会多一条。

30. **能力雷达**（dev，队友写的）：用林晓登录 → "我的档案"，技能上面是六维能力雷达，图下面的"技能归类"按六个轴列出具体技能和熟练度，看形状和下面那句"强项是什么、由几项技能撑起来、哪些轴还空着"对不对；改几项技能的熟练度保存，雷达图和技能归类会一起变。再点任意同学的名字，资料页的技能上方也有雷达和归类。换陈一舟登录，打开"数模冲刺队"：队伍页的"能力雷达"卡片里红色虚线是招募要求、黑色实线是自己，下面写着覆盖率、哪一轴达标、哪一轴差一档，再往下是"招募的技能要求，按能力归类"（每项技能写至少几级、这一轴缺什么角色）；队伍列表和比赛页"为你推荐"的队伍卡片上有需求小雷达。没勾技能要求的队伍只显示提示，不画需求线。想看得更完整，先跑一次 `sql/demo-radar.sql`，再在队伍页点"添加需求"试试新的技能字典（70 多项，按类别分组）。
31. **AI 能力分析 / 招募建议**（dev，队友写的）：用林晓登录 → "我的档案" → "AI 能力分析"，点"开始分析"（没配模型时会走本地规则，卡片右上角标"本地规则"）。看总结、优势、合作风格、建议补的技能和依据；勾一项、调熟练度、点"加入我的技能"，档案技能和雷达图应该跟着变，"重新分析"会重算。换陈一舟登录（数模冲刺队队长），队伍页会多一张"AI 招募建议"卡片，点"生成建议"，看最缺的能力、需求技能和队里现有水平的差距、该找什么样的人、面试问什么；非队长看不到这张卡。想真的走模型：在 `application-local.yml` 里打开大模型连接 `app.llm`（和 AI 整理共用），再加上 `app.ai.enabled: true`（允许把档案发给模型），重启后端再点重新分析，右上角会变成"AI 模型 · 模型名"。

## 已知问题和限制

目前没有已知的问题，发现了请提 Issue。

已经修好的：
- 队伍还剩两个名额时，队长同时同意两个申请，两个人都进了队但队伍还显示"招募中"，接着还能再同意一个，超员（v2.1.1 修好）。原因和改法见[数据库设计](数据库设计.md)第 8 节（隔离级别改成读已提交），并发测试 `team_race` 每轮都测这种情况。
- 履历的证明链接只收 http(s) 开头的网址：以前能填 `javascript:` 这类链接，别人点开会在本站执行脚本（资料页已经过滤了，自己的档案页没过滤；v2.1.1 修好）。
- 全天的个人日程在日历上多显示一天（一天的显示成两天），订阅到手机日历里也一样，估算每周空闲时也多算了一天。
- 演示比赛的日期写死了，10 月 15 日以后数学建模那届建不了队、申请被拦（见上面"怎么跑起来"）。
- 后端重启后不用重新登录了（#5）：登录状态平时放内存，同时存一份到数据库 `login_store` 表，启动时读回来。旧库的这张表在第一次启动时自动补上。
- 前端首次打开更快（#6）：Element Plus 改成按需引入，首屏 JS 从约 1.4 MB 降到约 340 KB，打包不再有体积警告。
- 已认证的人用没收录学校的邮箱重新认证，审核期间会保留原来的认证，驳回也不受影响（以前会变回"待确认"）。
- 队长被停用或暂停推荐后，他的队伍不再推荐给学生；被停用时队伍自动停止招募，待处理的申请作废，队员收到通知。
- 被暂停推荐的人会被反复暂停（队友修好，PR #17）：以前每轮互评揭晓都把历史上被评为经常失联或不交付的场次全数一遍，次数从不清零，管理员解除或 30 天到期后，下一轮一揭晓又被暂停。现在只在这一轮又被评为"经常"时才检查，只数上次暂停结束之后的场次。
- 队长看推荐队员时能看到候选人个人日程的标题（比如"医院复查"）（队友修好，PR #17）：现在只说"比赛期间 TA 有个人安排"，本人看推荐队伍时照样显示自己的标题。
- 管理员解除暂停后不到一秒里还算暂停、连点两次都"成功"：数据库的时间只到秒、存的时候会四舍五入成下一秒，现在先截到整秒再存。
