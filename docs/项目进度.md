## 怎么跑起来

按 [README](../README.md) 操作。几个容易卡住的地方：

- **Windows 用 PowerShell 导入 SQL**：PowerShell 不支持 `<`，`mysql` 一般也不在 PATH 里，用 README 里写全路径、`source` 的那种写法，一次导一个文件。
- **验证码在后端控制台**：开发模式不真的发邮件，注册和教育邮箱的验证码打印在后端窗口里。
- **演示账号**：导入 `sql/demo.sql` 后有 11 个账号，账号、身份和统一密码写在这个文件开头的注释里。
- **dev 上新增了表和字段**：已经建过库的不用删库重建，按顺序把 `sql/upgrade/` 里没跑过的脚本各跑一次（`2026-10-crawler.sql`、`2026-10-calendar-feed.sql`、`2026-10-login-store.sql`、`2026-10-notify-mail.sql`，写法见 README 的"第一次运行"）。
- **演示比赛的报名截止了**：以前导入的演示数据日期是写死的，数学建模那届 10 月 15 日就截止报名了，建队、申请、同意申请都会被拦。跑一次 `sql/demo-refresh-dates.sql` 把日期挪到今天附近（不删数据，可以重复跑）；新导入的演示数据按导入那天自动往后排。

## 测评指引

建议按下面的顺序测。每一步做完，觉得哪里不对、不好用、看不懂，就在 GitHub 上提一个 Issue。

### 第一版功能

1. **注册和认证**：注册一个新账号；用 `xxx@stu.example.edu.cn` 认证（自动通过）；再试一个没收录学校的 `.edu.cn` 邮箱（进入待审核）。
2. **比赛库**：筛选、看详情、关注一届比赛。
3. **个人档案**：填资料、技能、履历。
4. **问卷**：先填快速版，再补完整版。
5. **推荐**：用林晓登录看首页和比赛页的"为你推荐"，看推荐理由是否说得通；用陈一舟登录，看"数模冲刺队"页面的"推荐邀请的人"。
6. **组队流程**：申请 → 队长同意或婉拒；队长邀请 → 对方接受；退队、移出、转让队长、解散。
7. **日历**：开关图层；新建一个和比赛时间重叠的个人日程，看撞期提醒；试试每周重复、只删某一次。
8. **站内信**：上面每一步对方是否收到消息，点消息能不能跳到对的页面。
9. **管理后台**（管理员账号）：数据看板、认证审核（吴迪和郑好在等审核）、比赛库管理、匹配配置（改一个权重，回去看推荐分数变没变）、账号停用。

### 二期功能

10. **互评**：用赵子航把"国一冲冲冲"标记为比赛结束 → 赵子航和钱多多分别交互评 → 两人都交完后揭晓 → 右上角"互评与信用"看信用分。
11. **信用分对推荐的影响**：用陈一舟看"数模冲刺队"的推荐，周可（往届互评一般）会被降分并提示。
12. **举报**：在别人的队伍页举报 → 管理员在"举报与信用"里处理 → 举报人收到结果。
13. **截图认证**：新注册一个账号 → "身份认证"选"学生证截图"，上传学信网学籍页截图或学生证照片（可以自己画一张假的测试）→ 看识别结果 → 管理员在"认证审核"里看原图和比对结果后通过。
14. **通知抓取**（管理员账号，要联网）：管理后台 → 通知抓取，点"立即抓取"，会访问数模、电赛、计设的官网，一两分钟内抓完。现在是 10 月，大部分通知都是今年已经办完的，会被自动忽略，在"已处理"里能看到原因；"待确认"里打开一条，核对依据和原文后采用 → 去比赛库管理看生成的草稿届次。也可以在"抓取来源"里编辑一个来源，点"试抓"看列表里每个链接的去留原因。
15. **实时推送**：开两个浏览器窗口（比如一个普通窗口、一个无痕窗口），分别登录队长和另一个同学。同学申请入队，队长那边不用刷新，右上角马上弹出提示、铃铛数字加一，点提示进入队伍页；队长同意后，同学那边也马上收到。再开一个队长的标签页，在一个页面里把消息标为已读，看另一个页面的数字是否跟着变。
16. **分工待办**：队伍页右侧时间线里，在某个节点下点"+ 加任务"。队长把任务分给某个队员，对方马上收到通知；队员认领没人负责的任务、勾完成；看节点名旁边的"任务 x/y"有没有跟着变。去"我的队伍"页看最上面的"分给我的待办"。
17. **我的主页**：用不同的演示账号登录看主页。陈一舟（队长）右栏有孙悦的申请，直接点同意；林晓（还没组队）中栏是适合报名的比赛，右栏是推荐队伍。看顶部的下一个节点和本周可投入时间是否说得通，左边日历和学期赛程带上的横条、菱形对不对。
18. **订阅到手机日历**：主页右上的"订阅到手机日历"，下载 .ics 导入电脑日历，看比赛节点、队伍节点、个人日程是否都在；点"重置链接"后旧链接应该打不开。
19. **一句话添加**：在主页赛程日历上方的输入框里试几句，比如"明天下午两点到四点 队伍开会""周五前交论文初稿""每周六上午9点到12点 数模集训 到11月30日""今晚11点到明早1点 赶论文""下个月找时间开始复习线代 大概两周"，看输入框下面认出来的日期、时间、重复和标题对不对，回车后日历上有没有、顶部"本周可投入"有没有跟着变；认得不对的点"细调"改，并把那句话发到 Issue 里。
20. **邮件提醒**：消息页上方有"邮件提醒"开关（默认打开）。关掉浏览器，让别人给你发一条申请或邀请，10 分钟后看后端控制台（开发模式）有没有打印一封发给你的汇总邮件；开着网站、或者 10 分钟内看过的不应该发。

## 已知问题和限制

目前没有已知的问题，发现了请提 Issue。

已经修好的：
- 全天的个人日程在日历上多显示一天（一天的显示成两天），订阅到手机日历里也一样，估算每周空闲时也多算了一天。
- 演示比赛的日期写死了，10 月 15 日以后数学建模那届建不了队、申请被拦（见上面"怎么跑起来"）。
- 后端重启后不用重新登录了（#5）：登录状态平时放内存，同时存一份到数据库 `login_store` 表，启动时读回来。旧库要跑一次 `sql/upgrade/2026-10-login-store.sql`。
- 前端首次打开更快（#6）：Element Plus 改成按需引入，首屏 JS 从约 1.4 MB 降到约 340 KB，打包不再有体积警告。
- 已认证的人用没收录学校的邮箱重新认证，审核期间会保留原来的认证，驳回也不受影响（以前会变回"待确认"）。
- 队长被停用或暂停推荐后，他的队伍不再推荐给学生；被停用时队伍自动停止招募，待处理的申请作废，队员收到通知。
