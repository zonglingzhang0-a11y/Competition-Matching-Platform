# 组队匹配问卷 · 草案 v2

> v1 见 [问卷草案-v1.md](问卷草案-v1.md)。这一版根据外部反馈修改，设计依据和资料来源沿用 v1。

## 相比 v1 改了什么

| 改动 | 原因 |
|---|---|
| 每道题标明 **【两人】** 或 **【团队】** | 技能缺口、角色多样、有没有人带新人，都是看整个队伍的结构，不能当成两个人像不像来算 |
| 默认权重改为 目标 0.25 / 能力 0.20 / 协作 0.15 / **时间 0.20** / **责任 0.20**，并按比赛类型预设三套 | 时间冲突对短期比赛影响大；能力维度已经有两个团队打分器，降一点避免重复计分 |
| "两人都习惯截止前冲刺" 0.8 → **0.3**（短期集中型比赛 0.2） | 两个人都拖，风险会叠加。"拖延"和"夜猫子"本来就分成两题了 |
| "两人都想被老手带" 从两人分里拿掉，改成**团队资源分** | 这不是两个人合不来，是队里缺能带人的 |
| 时段重合去掉"少于 3 段记 0"，改成**按比例**，队伍例会时段权重 ×2 | 不该卡一刀 |
| 分歧处理的选项改成**具体做法**（当场说、冷处理、找第三方……） | 比抽象的类型更好答 |
| 新增：备赛期间的限制、贡献记录方式 | 反映中途退出的风险和资源限制；"贡献怎么记"和署名配套 |
| 署名题改成**比赛级**、**多选"能接受哪些规则"**，增加"轮换""按学校综测规则" | 问"能接受哪些"而不是"想排第几"，减少挑对自己有利的答案 |
| 中途退出的风险改成**乘法系数**，不靠自己说"我能坚持" | 这种题人人都会选"能坚持"，没有区分度。改用备赛限制、承诺声明和平台历史记录 |
| 开放题 3 道 → **1 道必填 + 2 道选填** | |
| 一票否决只留**客观事实**；"讨论不发言"之类只扣分 | 见文末 |
| 互评改成**频率量表**，加匿名汇总和异常检测 | 3 人小队很难真正匿名 |
| 预计用时改为 8–10 分钟，快速版 1–2 分钟 | v1 估得太乐观 |

## 结构

- **通用部分**：填一次，以后可以改，共 11 题。
- **比赛级部分**：每场比赛单独填，共 7 题，再加一个承诺勾选。
- **开放题**：1 道必填，2 道选填。
- **技能不在问卷里问**，直接读个人档案的技能标签，避免填两遍。

一共 18 题（其中 P5 不算进维度分，用来算承诺系数），加上开放题，完整版大约 8–10 分钟。

| 维度 | 默认权重 | 题目 |
|---|---|---|
| 目标与投入 | 0.25 | P1 目标、P2 每周投入、P3 冲刺强度、G1 动机 |
| 能力与角色 | 0.20 | 档案技能、P4 想承担的工作、G9 团队角色、G10 带新人 |
| 协作风格 | 0.15 | G6 同步频率、G7 决策方式、G8 分歧处理 |
| 时间与节奏 | 0.20 | G4 可用时段、G2 推进习惯、G5 回复速度、G3 作息 |
| 责任与底线 | 0.20 | G11 最不能接受的行为、P6 署名规则、P7 贡献记录 |
| （乘法系数） | — | 承诺系数 K：P5 备赛限制 + 平台历史记录 |

### 按比赛类型预设权重

比赛库里每场比赛有一个 `matchPreset` 字段：

| 预设 | 典型比赛 | 目标 | 能力 | 协作 | 时间 | 责任 |
|---|---|---|---|---|---|---|
| 默认 | 大多数学科竞赛 | 0.25 | 0.20 | 0.15 | 0.20 | 0.20 |
| 短期集中型 | 数学建模 72 小时赛、黑客松 | 0.20 | 0.20 | 0.10 | **0.30** | 0.20 |
| 长周期型 | 挑战杯、创新创业类、大创 | **0.30** | 0.20 | 0.15 | 0.15 | 0.20 |

短期集中型还会把 G2 里"两人都截止前冲刺"压到 0.2。

> 时间权重调高只是让时间合拍的人排在前面。真正撞期的情况，比如比赛期间和你参加的另一场比赛重叠，由一票否决直接处理，不靠权重。

## 通用部分（填一次）

### G1 你参加这类比赛主要为了什么？（最多选 2 项） · 【两人】tags · 目标 0.10

兴趣，想学东西 / 保研或综测加分 / 简历和求职 / 奖金 / 和朋友一起 / 学院或老师要求

### G2 你推进任务的习惯更接近？ · 【两人】single · 时间 0.25

A 拿到就开始，尽早做完 / B 按计划均匀推进 / C 前期慢慢想，后期集中发力 / D 截止前最有效率

|   | A | B | C | D |
|---|---|---|---|---|
| A | 1.0 | 0.8 | 0.4 | 0.1 |
| B | 0.8 | 1.0 | 0.7 | 0.3 |
| C | 0.4 | 0.7 | 0.8 | 0.5 |
| D | 0.1 | 0.3 | 0.5 | **0.3**（短期集中型 0.2） |

C 对 C 也从 1.0 降到 0.8：两个人都要等到后期才发力，中间空档太长。

### G3 你的作息更接近？ · 【两人】single · 时间 0.10

A 早起型 / B 正常 / C 夜猫子

相邻两档 0.7，A 和 C 之间 0.3。这题只问作息，不涉及拖延，所以两个夜猫子是 1.0。

### G4 一周里你通常哪些时段有空？ · 7 天 × 3 段 · 【两人】时段重合 · 时间 0.40

```
s = Σ_{共同空闲时段} w  ÷  min(Σ_{A 的时段} w, Σ_{B 的时段} w)
w = 2：队伍设置的例会时段；w = 1：其他时段
```

和队伍比时，B 用"全队共同空闲的时段"。不再卡阈值。

### G5 队友发来消息，你一般多久内会回复？ · slider 0–24 小时 · 【两人】· 时间 0.25

`s = max(0, 1 − |a − b| / 12)`

另外，如果队伍目标是冲国一（P1 选了 A），而候选人回复要 12 小时以上，这一题再乘 0.5。

### G6 你希望队里多久同步一次进度？ · 【两人】single · 协作 0.30

A 每天 / B 两三天一次 / C 每周一次 / D 有事再说

相邻两档 0.7，隔一档 0.3，A 和 D 之间 0。

### G7 队里有分歧时，你倾向怎么做决定？ · 【两人】single · 协作 0.30

A 队长拍板 / B 讨论后投票 / C 谁负责的部分谁决定 / D 讨论到大家都同意

匹配队伍时只和队长比。相邻两档 0.7，A 和 D 之间 0.3，其余 0.5。

### G8 和队友意见不一致时，你通常会？ · 【两人】single · 协作 0.40

| 选项 | 做法 |
|---|---|
| A | 当场说出来，语气可能有点冲 |
| B | 摆事实讲理由，一起找方案 |
| C | 先冷静一两天，再找时间谈 |
| D | 找队长或指导老师来判断 |
| E | 不想起冲突，就按别人的来 |

|   | A | B | C | D | E |
|---|---|---|---|---|---|
| A | **0.3** | 0.7 | 0.4 | 0.6 | 0.5 |
| B | 0.7 | 1.0 | 0.8 | 0.8 | 0.7 |
| C | 0.4 | 0.8 | 0.7 | 0.7 | 0.4 |
| D | 0.6 | 0.8 | 0.7 | 0.8 | 0.5 |
| E | 0.5 | 0.7 | 0.4 | 0.5 | **0.3** |

两个都冲（A 对 A）容易吵起来；两个都回避（E 对 E）问题会越积越多；一个冷处理一个回避（C 对 E），话就一直说不开。

### G9 在团队里，你更常扮演哪种角色？（选 2 个） · 【团队】角色多样 · 能力 0.15

选项同 v1，共 8 个，参考 Belbin 团队角色：想点子 / 定方向 / 分配协调 / 埋头执行 / 抠细节收尾 / 对接资源 / 挑毛病把关 / 照顾气氛。

```
s = 0.6 + 0.2 × 新增角色数 − 0.4 × 重复的稀缺角色数，限制在 [0, 1]
稀缺角色：定方向、分配协调、想点子
```

- 两个人都想定方向：0.6 − 0.4 = 0.2
- 两个人都埋头执行：不扣分，至少 0.6，带来新角色还会更高

### G10 关于经验，你更希望？ · 【团队】带新人资源分 · 能力 0.10

A 和经验差不多的人一起 / B 愿意带新人 / C 希望有经验的人带一带

不再两两比较，而是看队伍加入这个人之后的结构：

| 加入后的队伍 | s |
|---|---|
| 有人能带（选 B，或参赛 ≥ 2 次），并且有人想被带 | 1.0 |
| 没人想被带 | 0.9 |
| 想被带的人 ≥ 1，但没人能带 | 0.5 |

### G11 下面哪些队友行为你最不能接受？（选 3 项并排序） · 【两人】ranking · 责任 0.45

长时间失联 / 只挂名不干活 / 交的东西敷衍凑数 / 讨论时不发言 / 不打招呼就退队 / 改别人负责的部分不打招呼 / 争署名和排名 / 开会迟到或临时放鸽子

```
s = Σ_{两人都选了的项} (1 − |名次a − 名次b| / 3)  ÷ 3
```

快速版只选 1–2 项，不排序。

## 比赛级部分（每场比赛单独填）

### P1 这场比赛，你的目标是？ · 【两人】single · 目标 0.45

A 冲国家级一等奖 / B 争取省奖或国家级二三等奖 / C 有奖更好，重点是完整做一次 / D 先体验一下，量力而行

相容矩阵和 v1 相同，A 和 D 一票否决。

### P2 备赛期间，每周大约能投入多少小时？ · 【两人】slider 0–30 · 目标 0.35

`s = max(0, 1 − |a − b| / 10)`

### P3 冲刺阶段你能接受的强度是？ · 【两人】single · 目标 0.10

A 可以通宵 / B 熬到一两点 / C 尽量保持正常作息

相邻两档 0.6，A 和 C 之间 0.2。

### P4 这场比赛你想承担哪块工作？（按意愿排前 2） · 【团队】技能互补 · 能力 0.30

选项由比赛的"角色模板"决定，比如数学建模类是：建模 / 编程 / 论文写作与排版。

打分：第 1 意愿正好是队伍缺的角色，得 1.0；第 2 意愿是，得 0.6；都不是，得 0。

**档案技能**另外算一项，【团队】技能互补，能力 0.45：用档案里的技能标签和队伍缺口比，公式同 v1 的 B1。

> P4 问的是"想不想做"，档案技能是"能不能做"，两项都和队伍缺口比，但衡量的东西不一样。

### P5 这次参赛，你有哪些限制？（可多选） · 不算维度分，用来算承诺系数和过滤

**占用时间的事**：期中或期末考试 / 实习 / 考研、考公或考证 / 同期还有别的比赛 / 学生工作或社团职务

**其他限制**：只能线上参与 / 没有合适的电脑或设备 / 自费部分难以承担 / 英文读写比较吃力

**没有限制**

用途：
- 选了"只能线上"，而队伍设定为线下例会：直接降权，并在推荐理由里写明。
- 英文赛题（比如美赛）的队伍里，至少要有一人没选"英文读写吃力"：这是团队结构要求。
- 占用时间的事，用来算下面的承诺系数 K。

### P6 证书上的署名顺序，你能接受哪些规则？（可多选） · 【两人】集合交集 · 责任 0.35

按贡献记录排 / 赛前协商好写下来 / 队长第一，其余按贡献 / 多次参赛时轮流排前 / 按学校综测规则

`s = 1.0`：和全队能接受的规则有交集；`s = 0.2`：没有交集，推荐理由里提示"署名规则可能谈不拢"。

### P7 贡献怎么记录，你能接受哪些方式？（可多选） · 【两人】集合交集 · 责任 0.20

共享文档里的分工表 / Git 提交记录 / 每周简短周报 / 不需要专门记录

有交集记 1.0。只选了"不需要"的人对上要求记录的队伍，记 0.5。

### 承诺勾选（提交前，不计分）

☐ 如果中途确实无法继续，我会至少提前 3 天告诉队友，并交接我负责的部分。

勾选后会记录在案。中途退出却没有提前告知，会在互评里体现。

## 汇总规则

```
总分 = 100 × Σ_d (维度权重_d × 维度分_d) × K
维度分_d = Σ_i 题内权重_i × s_i
```

- **【两人】题**：候选人和队里每个成员分别算，取平均；G7 只和队长比。
- **【团队】题**：按候选人加入后的队伍结构来算。

**承诺系数 K = K历史 × K限制**，取值 0.6–1.0：
- **K历史**：新用户记 1.0，并显示"新用户"标签。有互评记录的，把信用分 0–100 线性映射到 0.6–1.0。
- **K限制**：P5 里"占用时间的事"中，和比赛期间重叠的项数记为 n。
  - 队伍目标是 A 或 B：K限制 = 1 − 0.1 × n
  - 其他目标：K限制 = 1 − 0.05 × n
  - 最低 0.7
- K 低于 1 时，推荐理由里写出原因，比如"备赛期间有实习，投入可能受影响"。

**推荐理由**：
- 把"权重 × 得分"最高的两题套模板，作为推荐理由。
- 得分最低的维度生成一句"组队前先聊聊"。
- K < 1 的原因单独列一行。

## 赛后互评

每个队员对其他队员逐项打分，频率量表：**从未 / 偶尔 / 有时 / 经常**。

1. 联系不上、长时间不回消息
2. 没按约定时间交付
3. 交的东西敷衍凑数
4. 讨论时不发言
5. 开会时在做别的事
6. 不打招呼就改别人负责的部分

前 5 项对应大学生团队搭便车研究里的几种表现，第 6 项来自 G11。用户不用另外再写一遍，问卷里的底线题和互评共用这套行为清单。

**防止报复和刷分：**
- **同时揭晓**：所有人提交后、或者截止时间到了，才一起生效。看不到别人给自己打了什么分，就没法针对性报复。
- **匿名汇总**：3 人小队里，谁给谁打的分很容易猜到，所以累计到 2 场比赛、或者 4 个以上评分人之后，才显示各项分数；在那之前只显示一个总的信用分。
- **异常检测**：某个评分人在多数题上和其他评分人的平均值差 2 档以上，就降低这个人打分的权重，并标记给管理员。
- **自评对比**：自己打的分和别人给的分差距多大，只有本人能看到，用来帮自己认识问题，不对外公开。

## 实现时的调整（M4）

匹配引擎在 `backend/.../match/MatchEngine.java`，单元测试直接读取 `sql/seed.sql` 里的配置。实现过程中，相对上面的规则做了两处调整：

1. **数据不全时，分数往中间收。** 只算有数据的题，会让只填了一两题的人凭一题高分排到前面。测试里，一个什么都没填的人拿了 90 分，排在填完问卷的人前面。所以现在：

   ```
   最终分 = 50 + (原始分 − 50) × 完整度
   ```

   完整度是有数据的题占的权重比例。问卷填全了分数不变；什么都没填就是 50 分，并提示"分数只供参考"。

2. **技能互补取最匹配的那条需求。** 原来的公式把队伍所有招募需求的技能合在一起算覆盖率。但一个人通常只承担一个角色，合在一起算会把分数摊薄。现在是逐条需求算，取最高的那条，推荐理由里也写明是哪个角色，比如"能补上「编程」需要的 Python"。

另外，"带新人"这一题（G10）只有在候选人自己答了、或者有参赛履历时才计分，否则说明不了候选人什么。
