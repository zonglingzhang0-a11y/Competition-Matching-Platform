# 功能介绍

更新于 2026-10-13。按角色介绍平台现有的功能，每项都写了在页面上的位置，方便对照着点。

- 第一到第四部分是**第一版 v1.0.0**（`main` 分支）的功能。
- 第五部分是**二期已完成**的功能，目前在 `dev` 分支。
- 进度、测评步骤和后续计划见 [项目进度](项目进度.md)。

## 一、学生能做什么

### 注册和身份认证（顶部菜单"身份认证"）

- 用任意邮箱加验证码注册。开发模式下不真发邮件，验证码打印在后端窗口里。
- 认证靠教育邮箱：给 `.edu.cn` 邮箱发验证码，学校已收录就自动通过，没收录的进管理员审核。
- 一个教育邮箱只能认证一个账号，认证有效到学年末（8 月 31 日）。
- 没认证也能逛比赛库、填问卷，但不能建队、不能申请入队。
- **没有教育邮箱也能认证**（二期，`dev` 分支）：上传学信网"学籍信息"页截图或学生证照片，填上和图片上一致的姓名、学校、入学年份。
  - 平台在自己的服务器上用 OCR 认字，和你填的比对，当场告诉你哪几项认出来了；图片不会发给任何第三方。
  - 然后进管理员审核。图片只有管理员能看，审核完立即删除，只保留认出来的文字。
  - 每人每天最多提交 3 次。
- 认证没通过时，页面上会显示管理员写的原因。
- 已经认证的人换学校（比如转学、读研）：新学校没收录时进管理员审核，审核期间保留原来的认证。

### 比赛库（"比赛库"）

- 能按关键词、学科、级别、"只看报名中"、"只看我关注的"筛选。
- 每个比赛显示当前这一届的报名状态，比如"报名中""即将截止"。
- 详情页有：
  - 届次信息：队伍人数上下限、是否限同校、是否需要指导老师；
  - 官方时间节点：时间没定的节点也能表示，比如"成绩公布：11 月中下旬"；
  - 队内分工模板，比如数模是"建模、编程、论文写作与排版"；
  - 这一届的队伍列表和"为你推荐"的队伍。
- 点"关注"后，这一届的节点会进你的日历，报名截止前也会提醒你。

### 个人档案（"我的档案"）

- 填资料、技能（入门 / 熟练 / 精通）、参赛履历。
- 微信、QQ、真实姓名只有队友看得到。

### 问卷（首页的提示进入）

- 分两部分：通用部分（性格、节奏、时间这类）和比赛级部分（这场比赛的目标、投入时间、想做哪块）。
- 有快速版（7 题）和完整版（22 题），先填快速版就能用推荐，以后再补全。
- 题型有单选、多选、排序、滑块、一周时段格子、承诺勾选。

### 日历（"日历"）

- 三个图层：关注的比赛的官方节点、所在队伍的里程碑、个人日程，可以分别开关。
- 有月、周、列表三种视图。时间没定的节点用虚线框表示。
- 个人日程支持每天、工作日、每周几重复，也能只删其中某一次；可以选择是否参与撞期检测。
- 撞期检测：个人日程和比赛时间重叠会标红，并在上方列出来。
- 在日历上拖选一段时间就能新建日程。

### 站内信（右上角铃铛）

- 申请、邀请、入队、退队、截止提醒、认证结果都会发站内信。
- 点开能跳到对应的页面。

## 二、队长能做什么

在队伍页（"我的队伍"进入）：

- **建队**：选届次、队伍人数、线上还是线下。同一届比赛一个人只能在一支队，数据库层面保证，并发操作也做过测试。
- **招募需求**：写清楚缺什么角色、几个人、要什么技能和最低熟练度。需求写得越清楚，推荐越准。
- **处理申请、发出邀请**：满员后自动变成"已满员"，还没处理的申请随之失效。
- **推荐邀请的人**：列出关注了这届、已认证、还没组队的人，按和你们队的匹配度排序，附带推荐理由。
- **队员管理**：移出队员、转让队长、停止或重新开放招募、解散队伍。
- **队伍时间线**：官方节点和队伍里程碑排在一起。队长增删节点，新增时通知队员；队员能勾"已完成"。
- **同校限制**：比赛要求同校组队时，系统会自动拦下外校的人。

## 三、匹配推荐怎么算

参考 date-match 的结构，**整套规则是可配置的**，管理员在后台就能调，不用改代码。详细规则见 [问卷 v2](问卷草案-v2.md)。

- **五个维度加权打分**：目标与投入、能力与角色、协作风格、时间与节奏、责任与底线。
- **每道题有自己的打分方式**，一共 10 种，比如：
  - 推进节奏用"相容矩阵"，两个人选项的契合度查表得出；
  - 空闲时段看重叠；
  - 技能看能不能补上队伍缺的那块；
  - 角色看队里的分工会不会重复。
- **一票否决**：目标差太远（一个冲国一、一个只想体验），或者比赛时间和他已经参加的另一场比赛撞了，直接不推荐。
- **乘系数**：
  - 备赛期间有考试、实习，分数会打折；
  - 只能线上参与、而队伍以线下为主，也会打折；
  - 比赛期间有个人日程，乘 0.9；
  - 二期以后还会乘上信用分。
- **数据少就往 50 分收**：只填了一两题的人不会凭一题高分排到最前面。
- **按比赛类型换权重**：数模这种几天打完的比赛更看重时间，互联网+这种做几个月的更看重目标。
- **给出解释**：每条推荐都附推荐理由、"组队前先聊聊"的话题和提醒，学生和队长看到的说法分别从各自的角度来写。

## 四、管理员后台（管理员账号，顶部"管理后台"）

| 页面 | 能做什么 |
|---|---|
| 数据看板 | 账号、队伍、申请概况；**技能供需缺口图**（队伍缺的人数和找队的人里会这项技能的人数对比），可以按届次筛选；各届组队情况 |
| 认证审核 | 审核学校没收录的邮箱，通过时收录邮箱后缀，同校排队的申请一起自动通过；审核截图认证，并排看原图和"填写的姓名、学校、入学年份在图里认没认出来"，图里认出已收录的学校会默认选上；不通过要写原因 |
| 学校与邮箱后缀 | 新建学校、增删邮箱后缀。加后缀时，能对上的待审核申请顺带通过 |
| 比赛库管理 | 比赛、届次（草稿 / 发布 / 归档）、官方时间节点。已经有队伍的届次不能删，只能归档 |
| 匹配配置 | 改维度权重、题目权重、相容矩阵和两个预设。保存前先检查再试算一次，存完推荐立刻按新配置算 |
| 账号管理 | 停用和恢复账号，停用后对方立刻被踢下线；他当队长的队伍自动停止招募，也不再出现在推荐里 |
| 举报与信用 | 二期新增，见下面 |

## 五、二期已完成（`dev` 分支）

### 比赛结束

队长在队伍页点"比赛结束"，录入奖项（可以不填）：

- 队伍归档，成员和招募需求不能再改；
- 每个队员的履历里自动记上这场比赛；
- 两人及以上的队开启赛后互评。

### 赛后互评（右上角菜单"互评与信用"）

- 7 天内匿名填写，每位队友 6 项行为，按"从未 / 偶尔 / 有时 / 经常"选，自评选填。
- 所有人交齐立即揭晓，否则到期自动揭晓；截止前 24 小时提醒还没交的人。
- 防报复、防刷分：
  - 揭晓前看不到别人打的分；
  - 和其他人差得太远的评分权重减半，并标记给管理员；
  - 累计 2 场比赛或 4 位评分人之后，才显示每一项的评价，避免猜出是谁打的。

### 信用分

- 由互评算出，满分 100，没有互评记录的显示"新用户"。
- 信用分会乘进推荐分，分数越低，推荐时越靠后，并提示"TA 的历史互评信用分是 xx"。
- 两场比赛都被多数队友评为"经常失联或不交付"的人，自动暂停推荐 30 天，并通知管理员复核。
- 用户卡片上显示"信用 xx"或"新用户"。

### 举报

- 在队伍页可以举报队伍或某个队员，选原因、写说明。
- 管理员在"举报与信用"里核实处理：暂停推荐 30 天、永久不推荐、停用账号或关闭队伍招募。
- 处理结果会通知举报人。
- 管理员还能查看、解除被暂停推荐的人，查看被判为异常的评分。
